# 生理期记录 App (Period Tracker)

一款简洁优雅的生理期追踪应用，帮助用户记录和了解身体变化的规律。

## 功能特性

- **日历视图** - 直观的月历展示，清晰区分月经周期不同阶段
- **智能标记** - 点击日期标记月经期，自动填充中间日期
- **健康记录** - 记录每日流量、痛经情况及描述
- **每日日记** - 记录心情和碎碎念
- **周期分析** - 根据历史记录计算平均周期和经期时长
- **预测功能** - 基于用户设置预测下一次月经期
- **健康知识** - 显示不同周期的生理变化知识
- **数据持久化** - 所有数据保存在本地浏览器，保护隐私
- **响应式设计** - 完美适配手机、平板、桌面端
- **触摸交互** - 支持左右滑动切换月份

## 技术栈

- [React 19](https://react.dev/) - UI 框架
- [Vite](https://vitejs.dev/) - 构建工具
- [Tailwind CSS 4](https://tailwindcss.com/) - 样式框架

## 使用说明

### 初次使用

首次打开应用会引导你设置以下信息：
- 上次月经开始日期
- 月经周期（默认 28 天）
- 月经持续天数（默认 5 天）

### 标记月经期

1. 在日历上点击日期
2. 切换「此日期是否为月经期」开关到「是」
3. 选择开始日期后，再选择结束日期，中间日期会自动填充

### 查看周期分析

点击「查看历史记录」按钮可以：
- 查看每次经期的开始/结束日期
- 查看经期持续天数和周期间隔
- 修改月经周期和持续天数设置
- 查看平均周期和平均经期时长

## 周期阶段说明

应用在日历上以不同颜色标记周期阶段：

| 颜色 | 阶段 | 说明 |
|------|------|------|
| 红色 | 月经期 | 月经来潮的阶段 |
| 绿色 | 卵泡期 | 月经结束后到排卵前的阶段 |
| 黄色 | 黄体期 | 排卵后到下一次月经来潮前的阶段 |
| 红色虚线 | 预测期 | 预测的下一次月经期 |

## 隐私说明

- 所有数据仅保存在本地浏览器的 `localStorage` 中
- 不会上传到任何服务器
- 清除浏览器缓存会导致数据丢失
- 请定期备份重要数据
